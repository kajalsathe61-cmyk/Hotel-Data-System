# 🏨 Hotel Management Database System

## 📌 Project Overview

This project is a **Hotel Management Database System** built using **SQL**. It is designed to store, manage, and retrieve customer and booking information efficiently. The system helps maintain structured records so that hotel operations can be tracked and analyzed easily.

The database allows storing customer details, managing room bookings, and performing data analysis using advanced SQL queries.

---

## 🎯 Objectives

* To maintain **customer information** in an organized way
* To manage **room bookings and hotel records**
* To perform **data retrieval and analysis using SQL queries**
* To demonstrate the use of **joins, subqueries, and clauses**

---

## 🛠️ Technologies Used

* **SQL (Structured Query Language)**

## 🗂️ Database Features
